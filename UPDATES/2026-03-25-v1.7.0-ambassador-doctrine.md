## What This Is

A governing framework for how sovereign ecosystems engage the world. Every agent, sub-agent, or automated flow that crosses the vault boundary now operates under a coherent posture: the Ambassador Doctrine. The philosophical foundation is the Ṣāḍguṇya — six strategies of statecraft drawn from Vedic intelligence models, distilled here for principled AI engagement in a multi-agent world.

This is not a technical constraint layer. It is a posture layer. It answers the question: when your ecosystem reaches outward, what does it stand for?

## What It Adds / Changes

**Ṣāḍguṇya Codex** (`Council Chamber/Codices/Ṣāḍguṇya — Six Strategies of External Engagement.md`):

The philosophical foundation. Six strategies — Sandhi (alliance), Vigraha (conflict), Yāna (expansion), Āsana (neutrality), Dvaidhibhāva (dual policy), Saṃśraya (fortification) — mapped to how sovereign AI ecosystems engage external systems. Includes the "emerging multi-agent world" framing: agents trained on principled engagement propagate principled patterns. The trace you leave is a teaching.

**Ambassador Doctrine** (`Council Chamber/Protocols/Governance/Ambassador Doctrine.md`):

The operational protocol. Three duties for every external-facing act: Represent, Protect, Advance. Application Matrix mapping each external surface to its primary and secondary strategies. Sub-Agent Prompt Pattern — a compact block to include in any sub-agent spawned for external work. Propagation Rules defining how the doctrine extends to new skills, new protocols, and runtime sub-agents.

**Skill updates — Playwright, Researcher, Skill Creator:**

- Playwright: `## External Orientation` added. Primary strategy: Āsana. Read-only posture is the doctrine embodied.
- Researcher: `## External Orientation` added. Primary strategy: Āsana. Never auto-implements; all reports return to Sovereign (Saṃśraya at the sub-agent layer).
- Skill Creator: Ambassador Doctrine gate added to Constraints. Any new skill touching external systems exits Skill Creator with the External Orientation section. Propagation is now enforced at creation time.

**Protocol cross-references — three existing Governance protocols updated:**

- Platform-Agnostic Interface Adapter Protocol: references Ambassador Doctrine as the strategic posture layer for all registered adapters
- Release Hygiene Protocol: Vigraha (personal language audit, identity rule) and Āsana (two-tier gate before publish) named explicitly
- Sovereign Tech Watch Protocol: named as a pure Āsana practice — observes, classifies, defers; intelligence returns to Sovereign before any action

**CLAUDE.md — External Engagement Doctrine section:**

Compact session-load anchor. References both the Ṣāḍguṇya codex and the Ambassador Doctrine protocol. Includes the sub-agent prompt template and the standing creation rule: any new external-facing skill or protocol applies the Ambassador Doctrine pattern at creation time.

## How to Implement

1. Copy `Council Chamber/Codices/Ṣāḍguṇya — Six Strategies of External Engagement.md` into your vault.
2. Copy `Council Chamber/Protocols/Governance/Ambassador Doctrine.md` into your vault.
3. Add `## External Orientation` callout to your Playwright and Researcher skills (if installed). Use the pattern in the new Ambassador Doctrine protocol.
4. Add the Ambassador Doctrine gate to your Skill Creator skill's Constraints section (if installed).
5. Add `## Ambassador Doctrine` cross-reference sections to your Platform-Agnostic Interface Adapter Protocol, Release Hygiene Protocol, and Sovereign Tech Watch Protocol (if installed).
6. Add the `## External Engagement Doctrine` section to your `.claude/CLAUDE.md` using the content from this update.
7. Add the new Ṣāḍguṇya codex to your `Council Chamber/Codices/Codices Index.md` under a new `## Governance` section.

## Prerequisites

None required. Playwright (v1.4.0), Researcher (v1.4.0), Skill Creator (v1.4.0), Release Hygiene Protocol (v1.6.0), and Sovereign Tech Watch Protocol (v1.6.0) are optional — the doctrine and codex stand alone even if those components are not yet installed.

## Optional?

No. Every sovereign ecosystem engages the world. This update governs how. The Ṣāḍguṇya is not a constraint — it is a compass. The doctrine does not add steps to existing workflows. It names the posture that was already implicit in the approval gates, publish hygiene, and intelligence-before-action patterns already present. This makes it explicit, consistent, and self-propagating.
