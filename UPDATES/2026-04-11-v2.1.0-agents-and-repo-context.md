## What This Is

Two additions that establish how AI coding tools orient to this repo and any repo you build alongside your ecosystem. AGENTS.md is the root context file that any AI tool reads automatically. The Repo Context Architecture Protocol defines the two-layer standard for extending this pattern to every external repo you operate.

## What It Adds / Changes

- `AGENTS.md` at repo root — project identity, ecosystem position, stack, build commands, critical rules, content and voice guidelines, AI discoverability status, and cross-ecosystem links
- `Council Chamber/Governance/Public Publish Audit - 2026-03-09.md` — historical publish audit from the initial release arc; documents what was reviewed and resolved before v1.0
- `Council Chamber/Protocols/Governance/Repo Context Architecture Protocol.md` — defines the AGENTS.md + CLAUDE.md two-layer standard for any ecosystem-adjacent repo

## How to Implement

1. `AGENTS.md` is already present at repo root. No action needed — your AI tools will discover it automatically on next session load.
2. Review `AGENTS.md` and update the **Ecosystem Position** table to reflect your actual nodes (replace Lane's URLs with your own sites and repos).
3. Review `Council Chamber/Protocols/Governance/Repo Context Architecture Protocol.md`. Update the **Active Instances** table at the bottom to track your repos.
4. When creating any new site repo or public repo adjacent to your ecosystem, follow the Initialization Sequence in the Repo Context Architecture Protocol: write AGENTS.md first, then CLAUDE.md with `@AGENTS.md` at top.

## Prerequisites

None. Works on any initialized Sovereign Ecosystem instance.

## Optional?

No. AGENTS.md is the universal AI context layer for this repo. All AI coding tools benefit from it immediately.
