## Posture Shift

This update establishes a distinction that earlier versions did not have:

**Foundation:** the minimum viable Sovereign Ecosystem. Governance, capture, planning, archival, session rhythm. Lean.

**IGOS Public Library:** cool extras. Practitioners pick what fits. Skills, protocols, codices, strategies. At infinitegameos.io.

The two surfaces are linked. Source Harvest is the canonical example: ships in the Foundation as a starting tool, also ships in the IGOS library as a downloadable plugin so practitioners outside the Foundation can install it standalone.

Future graduations will follow this same pattern. Foundation stays small. Library scales.

## How To Adopt

For existing Sovereign Ecosystem builds:

1. Pull the v2.4.0 release. Your local skill folders for the five graduated skills will still exist locally; the SE template no longer ships them, but your existing copies remain in your vault.
2. If you want the graduated skills as installable plugins instead of vault folders, install them from infinitegameos.io and remove the local folders.
3. If you do not use AI-assisted plan execution, you can let Pending Plan Implementation lapse entirely. The protocol still governs the artifact shape.

For new builds:

1. Install the Foundation as usual.
2. Visit infinitegameos.io to browse the public library.
3. Install graduated skills as plugins on demand.

The Ecosystem Update Check Skill will surface this update when run.
