## What This Is

Two refinements shipped together. The Constitution now carries an explicit Foundational Covenant — seven operative commitments governing the human-AI relationship at the substrate level. The install guide now routes new practitioners through the IGOS page first, with GitHub as the secondary path.

## What It Adds / Changes

- **Article XIII — Foundational Covenant** added to the Constitution. Seven commitments distilled into ecosystem-native governance language: Generational Stewardship, Transparent Process, Benevolence as Default, Consent as Foundation, Reciprocal Responsibility, Authentic Unfolding, Active Uplift. Not aspirational. Operative.
- **Quick Start Guide download step** updated to lead with `infinitegameos.io/sovereign-ecosystem` (the Download ZIP button) and reference GitHub as an alternative for the technically familiar.
- **PDF versions** of both the Quick Start Guide and Build Sequence now ship directly in the `Getting Started/` folder alongside their markdown sources. Included in the ZIP download out of the box.

## How to Implement

**For the Foundational Covenant:**
Your AI can read Article XIII in `Council Chamber/Governance/Constitution - Sovereign Ecosystem.md`. No structural changes required. The seven commitments are operative — they inform how your AI engages by default. No additional configuration needed.

**For the Quick Start Guide update:**
The new IGOS link in Step 2 points to `infinitegameos.io/sovereign-ecosystem`, which always serves the current release. If you have previously shared the GitHub URL with someone onboarding, the IGOS page is the better link going forward.

**For the PDFs:**
Both guides now exist as PDFs in `Getting Started/`. Print them if you want a physical reference for the build sequence. They stay current with the markdown.

## Prerequisites

Foundation build complete (Session 1 minimum).

## Optional?

No — the Covenant is a constitutional addition. The install guide refinements are low-friction improvements.
