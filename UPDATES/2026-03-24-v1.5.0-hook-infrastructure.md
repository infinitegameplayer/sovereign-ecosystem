## What This Is

Two hooks and a silence file. The hooks close a continuity loop that /compact would otherwise break. The silence file tells Claude what not to load — keeping context lean and fast.

**PreCompact + PostCompact hooks:** When Claude runs /compact to compress its context window, it loses active session state. The PreCompact hook captures a snapshot to `.runtime/pre-compact-state.md` before compression fires. The PostCompact hook reads it back immediately after. Long sessions (weekly reviews, coaching, multi-session builds) no longer lose their thread mid-run.

**`.claudeignore`:** Works like `.gitignore` but controls what Claude loads into context. Without it, Claude reads everything it can find — including `node_modules/`, git history, log files, and runtime artifacts. With it, context stays focused on what matters.

## What It Adds / Changes

- `Council Chamber/scripts/hooks/pre-compact-state-capture.sh` — writes `.runtime/pre-compact-state.md` before /compact fires
- `Council Chamber/scripts/hooks/post-compact-reorienter.sh` — re-injects that state after /compact completes
- `.claudeignore` at vault root — excludes `node_modules/`, `.git/`, `.trash/`, `*.log`, `Council Chamber/scripts/node_modules/`, `Council Chamber/scripts/package-lock.json`, `.runtime/`

## How to Implement

1. Copy the hook scripts into your vault:
   - `Council Chamber/scripts/hooks/pre-compact-state-capture.sh`
   - `Council Chamber/scripts/hooks/post-compact-reorienter.sh`

2. Make the scripts executable (Mac/Linux only):
   ```bash
   chmod +x "Council Chamber/scripts/hooks/pre-compact-state-capture.sh"
   chmod +x "Council Chamber/scripts/hooks/post-compact-reorienter.sh"
   ```

3. Copy `.claudeignore` to your vault root. Customize the patterns as needed for your build.

4. Register the hooks in `.claude/settings.json`. Add this inside the `"hooks"` object (create the file if it does not exist):
   ```json
   "PreCompact": [
     {
       "matcher": ".*",
       "hooks": [
         {
           "type": "command",
           "command": "bash \"[your-vault-path]/Council Chamber/scripts/hooks/pre-compact-state-capture.sh\""
         }
       ]
     }
   ],
   "PostCompact": [
     {
       "matcher": ".*",
       "hooks": [
         {
           "type": "command",
           "command": "bash \"[your-vault-path]/Council Chamber/scripts/hooks/post-compact-reorienter.sh\""
         }
       ]
     }
   ]
   ```
   Replace `[your-vault-path]` with the absolute path to your vault root (e.g. `C:/Users/YourName/Documents/MyEcosystem` on Windows or `/Users/yourname/Documents/MyEcosystem` on Mac).

5. The `.runtime/` directory is created automatically by the hook on first run. Add it to your `.gitignore` if you track your vault in git.

## Prerequisites

None. Works independently of other updates.

## Optional?

No — continuity across /compact is a core Claude Code pattern. The `.claudeignore` is especially high-value if your vault includes `node_modules/` from Playwright (v1.4.0) or other installed packages.
