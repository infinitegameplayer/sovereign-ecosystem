## What This Is

A new `llms.txt` file at the repo root. It is the navigation manifest for AI agents arriving at the repository. Where AGENTS.md declares behavior, llms.txt declares structure. The two operate as a layered manifest: agents read llms.txt to discover what the ecosystem is and how it is organized, then read AGENTS.md to learn how to interact with and harvest from it.

The file leads with an atomic, AI-quotable definition of the Sovereign Ecosystem, carries a short FAQ of the questions a builder actually asks, indexes the repository structure, names the core concepts and links the surrounding ecosystem. The README stays a human onboarding document. The citation load lives here, on a surface humans rarely open by hand. Human and machine audiences never share a page.

## What It Adds / Changes

### Adds llms.txt

New root file. Sections: What It Is, Frequently Asked Questions (seven atomic Q&A pairs), Repository Structure, Core Concepts, Ecosystem cross-links and How to Reference. Format follows the llms.txt navigation-manifest convention: H1 title, blockquote summary, intro paragraph, then descriptive H2 sections. The opening line is the atomic definition AI agents quote.

## How to Implement

The AI Interface (Claude Code) executes the following from the working directory:

1. Create `llms.txt` at the repo root with the navigation-manifest content. Lead with the atomic definition. Keep the FAQ to questions a real builder asks, answered atomically.

2. Confirm AGENTS.md is present at root as the behavior layer. llms.txt references it as the companion surface.

3. A forking user adapts llms.txt to their own ecosystem the same way they adapt AGENTS.md and README. The upstream file names the original author and the surrounding ecosystem. A user's instance carries their own.
