## What This Is

The template is a fork of a working vault that stopped receiving updates the day it was published. The vault heals itself continuously and its descendants inherit nothing. This release is the first deliberate harvest across that gap: nine things the source vault has and the template lacked, ruled one by one and ported.

**Apply this if you installed any version of this template.** Everything here is additive. The two hooks are new guards, not fixes to guards you already run. The codices and skills are new coverage. None of it is a hole an attacker walks through. Each is coverage the template should have carried and did not.

## The Governing Idea

Two of the guards below were found broken in the source vault and fixed there in the same week. The people running this template had neither the guard nor the fix, which is to say they had nothing where a guard should be. A bug fixed in a private vault and not in the template is a divergence from the moment it lands. This release closes nine of them.

The ruling was made candidate by candidate on one question: does a stranger who cloned this template need this, or is it private scaffolding. Six other candidates were ruled to stay home for that reason, including a product-catalog sweep and infrastructure skills that assume a substrate the template does not have.

## The Guards

**`post-bash-encoding-check.sh`** is a mojibake detector. After a Bash or PowerShell operation it scans vault Markdown files modified in the last sixty seconds for the byte signature left when a tool reads a UTF-8 file as Windows-1252 and writes it back. An em dash becomes `â€"`, a curly quote becomes `â€™`, and the corruption spreads through a file quietly. The fix at the moment of writing is an explicit UTF-8 encoding on every PowerShell file operation, and this hook catches the damage when the fix was forgotten.

It watches the PowerShell tool, because PowerShell is the tool that causes the corruption. A detector registered on Bash alone is blind to the one door it exists for. That is not hypothetical: it is exactly how this hook shipped in the source vault before the week it was proven, registered on Bash, watching everything except the thing it was built for.

**`post-bash-move-audit.sh`** enforces the Move audit rule. After a plain `mv` of a Markdown file it runs a full-vault wikilink grep for the old path and surfaces every reference to the old name that was left behind. The move and the sweep are one unit of work, and a stale wikilink from a prior move is a recurring defect class this closes at the moment of the move.

It carries three fixes from the week it was proven. It classifies the source before it greps, so a file moved outside the vault is skipped rather than swept. It ignores stems shorter than four characters, which cannot be a meaningful reference. Every grep runs under a fifteen-second ceiling. Before those fixes a move of a short-named file outside the vault, `mv /tmp/a.md /tmp/b.md`, sent the hook grepping the entire vault for the letter `a` and stalled the session with no output.

Both are registered on `Bash|PowerShell` in `.claude/settings.json`, resolving the vault root from `SOVEREIGN_VAULT_ROOT` exactly like the hooks already shipped.

**Both ship with their positive control.** `hooks-selftest.mjs` gains six cases: the mojibake signature warned on, the PowerShell tool watched, the referenced move flagged, the unreferenced move left quiet, and the stall regression timed rather than trusted. The suite runs `pass=18 fail=0` with the two guards included. A guard travels with the test that proves it refuses what it claims to refuse. That is the standing law of this template since v3.4.0, and these two arrive already holding it.

## The Doctrine

The template shipped code, guards and self-tests, and carried no doctrine at all on how to steward software you hand to other people. This release adds the first Technology codices.

**`Sovereign Software Codex`** is the posture on software you may one day give away. Its core is three rules. Positive control travels with the guard, because a guard the recipient trusts more than nothing and that does nothing is worse than no guard. The clean clone is the only witness, because a working directory carries local fixes and set variables that a stranger's clone does not. Ship the spec plus the test, never a diff, because the recipient's copy is customized and your diff will not apply. This is the doctrine that would have caught the v3.3.1 deletion hole in your own forks before it shipped.

**`Engineering Codex`** is the standard for code work across the ecosystem. Plan, build, verify, upgrade, and the return arrow that turns a solved bug into a durable `docs/solutions/` note so the same root cause is never diagnosed twice.

## The Tooling and the Skills

**`check-skill-mirrors.mjs`** confirms every canonical skill has its interface mirror and names any that drift. **`validate-doc-claims.mjs`** checks that a document's citations resolve against git at the moment of the check, the mechanical face of the Move audit rule. Both resolve the vault root from `SOVEREIGN_VAULT_ROOT`.

Three skills join the library. **Systematic Debugging**, the Iron Law of no fix before the root cause. **Brainstorm**, the design-before-you-build gate with one question at a time and a three-solution fork before any code. **PR Code Review**, a multi-dimension parallel review of a pull request before merge.

## How To Apply

Copy the eleven files named in `affects` into the matching paths in your build. Register the two new hooks by adding the `Bash|PowerShell` PostToolUse block from `.claude/settings.json`. Then run `hooks-selftest.mjs` and confirm `fail=0`, which is the proof that the guards you just installed actually fire. Regenerate your Skills Index with `build-skills-index.mjs` so the three new skills enroll.

## How You Learn That A Fix Shipped

Nothing reaches a templated clone automatically. There is no dependency graph and no notification. The one click that closes the gap is Watch, Releases only, on the repository. This release, like every one before it, ships through the CHANGELOG, this package, and a tagged GitHub release together.
