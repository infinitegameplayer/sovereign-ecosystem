## What This Is

Four CLAUDE.md additions and one new protocol that sharpen how the AI Interface reasons under uncertainty and how it composes substrates. The Cross-Model Perspectives section names when to reach for another model substrate and why. The Three Solutions Rule sets a decision posture for any moment where the AI Interface needs Sovereign input. Edit-Time Discipline tightens small-edit posture. Verify Worker Findings names the orchestration discipline around subagent and external worker output. Held-by-Structure makes explicit that the ecosystem holds its own discipline.

These are invisible improvements. The ecosystem does the same kinds of work it did before. The work gets sharper.

## What It Adds / Changes

### Adds to CLAUDE.md

- **Cross-Model Perspectives section** (new top-level section between Session Calibration and Expression Standards). Names four standing questions that fire at decision-density moments and maps each to a substrate type (web-current research, independent challenger, cheap-parallel external workers, complementary corpus). Defines perspective as distinct from dispatch. Names the sanitization rule for any output that flows back into ecosystem artifacts.

- **Held-by-Structure principle** (new bullet in Session Calibration). The ecosystem holds its own discipline. Reviews happen at scheduled moments, not on demand. The AI Interface does not nudge the Sovereign.

- **Edit-Time Discipline subsection** (new under Operational Efficiency). Three rules for small code edits: surface assumptions before acting, match existing style, every changed line traces directly to the request.

- **Verify Worker Findings subsection** (new under Operational Efficiency). Orchestrator verifies subagent and external worker output against live state before treating it as authoritative.

### Adds Council Chamber/Protocols/Governance/Three Solutions Rule.md

New protocol. When the AI Interface does not know the next move or when multiple paths are viable, it surfaces three options it genuinely believes in, states a recommendation, names the trade-off, and lets the Sovereign decide. Four guardrails govern application. The protocol also describes the trust ladder from early-phase back-and-forth to mature-phase Sovereign-veto posture.

## How to Implement

The AI Interface (Claude Code) executes the following steps from the working directory:

1. Open `.claude/CLAUDE.md`. Locate the line ending the Session Calibration section. Add the Held-by-Structure bullet immediately after the last existing bullet. Add the Cross-Model Perspectives section between the closing bullet of Session Calibration and the `## Expression Standards` heading. The Anti-AI Writing Patterns Codex reference in Expression Standards comes in v2.8.1.

2. In the Operational Efficiency section of CLAUDE.md, locate the Infrastructure-First subsection's last bullet. Add the Edit-Time Discipline subsection (three bullets) and the Verify Worker Findings subsection (three bullets) immediately after, before the `## Planning and Execution` heading.

3. Create `Council Chamber/Protocols/Governance/Three Solutions Rule.md` with the full protocol content. Status field is `active`.

4. The Sovereign reviews the additions for fit with their actual operating posture and adjusts wording where the template register does not match their voice.
