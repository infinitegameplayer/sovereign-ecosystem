## What This Is

A documentation pass that lets this template and the Infinite Game OS public library read as one connected ecosystem. v3.0.0 opened the dual-distribution path. This release names the wider library on the surfaces a human and an agent each read first, and it points both at the installable set with direct page URLs. No new behavior. No new skills. The seam itself is the work.

## What It Adds / Changes

**README.md (`The Wider Library` section, after Foundation First):** A two-paragraph addition. It names the full library at infinitegameos.io/skills (twenty installable skills, seven bundles, one governing protocol), names the five skills that were born in this template before they graduated outward (Pending Plan Implementation, Plan Challenger, Researcher, Skill Creator, Systematic Debugging), and notes the four that ship in both homes (Source Harvest, Self-Healing, Session Closeout, Playwright). Sovereignty framing throughout. The library is an open shelf, not a store.

**llms.txt (Ecosystem section):** The existing dual-distribution paragraph gains a short follow-on naming the full library scale, then two enumerated blocks. Graduated Skills lists the five with their direct page URLs. Dual-Distribution Skills lists the four with theirs. One line each. An agent arriving at the repo can now discover the installable set programmatically without leaving the manifest.

## How to Implement

1. **Pull the README addition.** Add the `The Wider Library` section after `Foundation First`. It carries no dependency beyond the live library at infinitegameos.io/skills.

2. **Pull the llms.txt addition.** Add the library-scale line and the two enumerated blocks to the Ecosystem section, after the existing dual-distribution paragraph from v3.0.0.

3. **Confirm the counts against your own library if you forked one.** The shipped numbers (twenty skills, seven bundles, one protocol) describe the Infinite Game OS public library. If you run your own public library, update the counts and the page URLs to match yours.

## Prerequisites

v3.0.0 (The Plugin Era) installed. The dual-distribution paragraph this release builds on arrived in v3.0.0.

## Optional?

No. This is a discoverability seam on the two surfaces agents and humans read first. It carries no behavior change and no install cost.
